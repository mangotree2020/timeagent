# 이동 중 지도·음성 안내 제품 명세

마지막 업데이트: 2026-07-26  
참여 관점: PO, 모바일 아키텍트(MD), 전문 모바일 앱 디자이너

## 제품 결정

- 준비 타임라인의 `이동` 단계 진입 시 전용 `/journey` 화면으로 전환한다.
- MVP는 포그라운드 이동 안내를 우선한다. 잠금 화면·앱 종료 후 연속 음성 안내는 별도 네이티브 기술 검증과 스토어 정책 검토 후 제공한다.
- 사용자의 실제 현재 위치 마커와 정확도 범위, 목적지, 선택 경로, 남은 거리, 도착까지 시간, 약속까지 시간을 함께 표시한다.
- `도착까지 17분`과 `약속까지 24분`을 구분하고 예상 도착 시각과 여유/지각도 표시한다.
- TMAP 보행자 API에서 받은 maneuver를 의미 있는 안내 지점으로 사용한다. 경로의 모든 좌표를 음성으로 읽지 않는다.
- 도착 반경 진입이나 경로 변경 제안은 자동 적용하지 않고 사용자가 확인한다.

## 360×800 기준 화면 구조

1. 전체 화면 NAVER 지도
2. 상단 앱바: 최소화, 목적지명, 더보기
3. 상단 상태 카드: `도착까지`, `약속까지`, 예상 도착, 여유/지각, 음성 상태
4. 하단 시트: 선택 수단·남은 거리·소요 시간, 다음 행동, 데이터 갱신 시각, 도착 확인 CTA
5. 지도 컨트롤: `내 위치로`, `음성 켜기/끄기`
6. 확장 시트: 교통수단별 총 소요 시간, 총 거리, 도보 거리, 환승/비용, 예상 도착, 실제/추정 데이터 구분

현재 위치는 cyan 원, 흰색 외곽선, 정확도 halo와 진행 방향으로 표시한다. 선택 경로는 흰색 casing 위 navy 선으로 표시하고, 이미 이동한 구간과 남은 구간을 색상 외 굵기와 문구로도 구분한다.

## 교통수단 데이터 계약

- TMAP 보행자 API 연결 전에는 도보 경로도 fixture임을 표시한다.
- TMAP 보행자 API 연결 후 도보만 `실제 경로`로 표시한다.
- 버스·지하철·자동차·택시는 해당 경로 API 상품이 정해질 때까지 `기본 추정`으로 표시하거나 숨긴다.
- 모든 결과는 provider, 계산 시각, 거리(m), 소요 시간(s), stale 여부를 포함한다.
- 다른 수단을 선택하면 시간·거리·비용·도착의 변경 전후를 먼저 보여 주고 사용자가 적용할 때만 진행 세션을 바꾼다.

## 음성 안내 규칙

- 출발 시 전체 경로 요약
- 회전 약 200m 전과 30m 전
- 횡단보도, 출구, 승하차 전환
- 경로 이탈과 새 경로 제안
- ETA가 2분 이상 변하거나 약속 여유가 지각으로 바뀔 때
- 목적지 100m 전과 도착 확인 요청

같은 maneuver는 한 번만 읽고 기본 15초 cooldown을 둔다. 화면에는 최근 안내 문장, 음소거 상태와 `다시 듣기`를 항상 제공한다. TalkBack 활성 시 TTS와 live-region의 중복 낭독을 방지한다.

## 오류·복귀 상태

- 위치 탐색 중: skeleton, `현재 위치를 찾는 중`, 다시 시도, 수동 출발지
- 권한 거부: 목적지·ETA·거리·다음 행동 텍스트 유지, 설정 이동과 수동 위치
- GPS stale: 마지막 위치 시각과 정확도 낮음 표시, 재탐색
- 네트워크/timeout/429/5xx: 마지막 정상 경로와 기준 시각 유지, `추정` 표시, 재시도
- 지도 렌더 실패: 주소, ETA, 거리, 다음 행동, 갱신 시각, 음성 상태를 제공하는 텍스트 전용 모드
- 앱 복귀: 경과 시간 보정, 권한 재조회, last-known 후 fresh 위치 조회, route TTL/이탈 확인, 알림 재조정

## 수용 기준

- Given 이동 단계에 진입하고 위치·경로가 유효함, When 화면이 열림, Then 3초 안에 도착까지 시간·다음 행동·선택 수단·남은 거리를 스크롤 없이 확인한다.
- Given 현재 위치가 갱신됨, When 마커와 ETA가 바뀜, Then 초 단위 변화는 접근성으로 반복 낭독하지 않는다.
- Given 의미 있는 waypoint를 통과함, When 안내 조건을 만족함, Then 화면 문구·TTS·선택 진동이 한 번만 발생하고 다시 들을 수 있다.
- Given 네트워크가 끊김, When 새 경로를 받을 수 없음, Then 마지막 경로의 기준 시각과 추정 상태를 표시하고 지도 없이도 다음 행동을 유지한다.
- Given 다른 교통수단이나 새 경로를 선택함, When 적용 전임, Then 변경 전후를 표시하되 세션을 바꾸지 않는다.
- Given 목적지 반경에 들어옴, When 자동 감지가 발생함, Then 사용자 확인 없이는 일정을 완료하지 않는다.

## 현재 UI에서 발견한 개선 작업

### P1 신뢰·이동 경험

- 홈의 사용자명·날짜·카운트다운과 알림 fixture를 실제 세션 값으로 교체
- Progress 닫기를 `진행 최소화`로 명확히 하고 홈에 `이동 계속 보기` 진입점 제공
- 단계 완료 후 5초 실행 취소 또는 최근 단계 복구 제공
- `완료`와 `건너뛰기`를 서로 다른 기록 사유로 분리
- 설정의 `음성으로 일정 제어`와 `이동 음성 안내`를 분리
- 경로 provider·갱신 시각·위치 사용 중 상태를 지속 표시
- Android에서 권한 API가 허용이어도 시스템 앱 알림 스위치가 꺼진 상태를 구분하고, 실제 수신 불가 문구와 시스템 설정 이동을 제공

### P2 접근성·완성도

- 문자/emoji 아이콘을 일관된 벡터 아이콘과 접근성 레이블로 교체
- 200% 폰트에서 비교 표와 3열 지표를 세로 카드로 전환
- 알림 목록에 읽음 상태, 연결 일정과 딥링크 추가
- 이동 화면 터치 대상 48×48 이상, 본문 16px 이상, 야외 대비 4.5:1 이상 적용

## 기술·보안 선행 조건

- NAVER Geocoding 서버 프록시에는 Client ID와 Client Secret이 모두 필요하다. Secret은 확보 전 구현 완료로 표시하지 않는다.
- TMAP App Key는 서버 전용으로 유지하고 앱 번들·문서·로그에 넣지 않는다. 대화에 노출된 키는 운영 사용 전 회전한다.
- `EXPO_PUBLIC_MOBILITY_API_BASE_URL`을 통해 정규화된 `/v1/geocode`, `/v1/routes/walk`만 앱에서 호출한다.
- NAVER native map bridge가 Expo 57, RN 0.86, New Architecture에서 빌드되는지 최소 지도 spike로 먼저 확인한다.
- 백그라운드 위치·연속 음성은 Android foreground service와 iOS background mode의 별도 릴리스 범위다.

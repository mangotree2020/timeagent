# 제품 요구사항

## 제품 정의

ON:TIME은 약속 알람이 아니라 행동 시작 안내 앱이다. 약속 시간과 장소를 입력하면 준비 행동, 출발, 이동, 도착을 연결하고 실제 진행이 늦어질 때 남은 계획을 다시 계산한다.

## MVP 가설

- 사용자는 1분 안에 첫 일정을 만들 수 있다.
- “지금 무엇을 해야 하는가”가 3초 안에 이해된다.
- 지연 시 최대 3개의 대안을 비교하면 현실적인 선택을 빠르게 할 수 있다.
- 실제 소요 시간을 다음 계획에 반영하면 정시 도착률이 높아진다.

## 핵심 사용자

- 준비 시작 시점을 자주 놓치는 대학생
- 연속 일정과 이동 시간을 함께 관리해야 하는 직장인
- 준비 루틴이 길고 일정마다 달라지는 사용자

## MVP 범위

### 포함

- 3단계 일정 등록: 약속, 이동, 준비 행동
- AI 준비 계획과 세로 타임라인
- 실시간 현재 단계, 카운트다운, 완료/지연/건너뛰기
- 지연 재계산과 변경 전후 요약
- 플랜 B: 다음 버스, 지하철, 택시
- 완료 회고와 실제 소요 시간 저장 모델
- 기본 위치, 루틴, 이동 우선순위, 알림, 권한 설정
- 기기에 연결된 Google·Apple/iCloud·Android 캘린더 일정 조회와 명시적 가져오기
- 앱 실행 시 Google 계정 로그인과 로그인 상태 복원
- 선택 안 함·여성·남성 중 사용자가 고른 기준으로 새 일정의 기본 준비 항목 추천
- 현재 위치의 날씨·기온·체감온도·최고/최저·강수확률과 일정 준비 행동 안내

### 후순위

- 친구 공유, 다중 사용자 약속 조정
- 고급 습관 리포트와 구독
- 완전한 캘린더 대체 기능
- Apple·Kakao 등 추가 소셜 로그인

## 핵심 흐름과 수용 기준

### 첫 일정 생성

Google 로그인 → 온보딩 → 권한 설명 → 홈 빈 상태 → 3단계 입력 → AI 계획 → 확정.

- 필수 입력과 추천값을 구분한다.
- 입력은 자동 저장되며 장소 검색 실패 시 직접 입력할 수 있다.
- Google 로그인을 완료해야 앱 내부 화면으로 이동할 수 있다.

### 기기 캘린더에서 일정 가져오기

일정 탭 → 캘린더 연결 설명 → 읽기 권한 허용 → 캘린더/날짜별 일정 확인 → 가져올 일정 선택 → 초안 확인·수정.

- 앱은 기기에 동기화된 Google Calendar, Apple/iCloud Calendar, Android 로컬·계정 캘린더만 읽으며 별도 클라우드 로그인이나 서버 복제를 요구하지 않는다.
- 운영체제 권한 팝업 전에 읽는 기간과 사용 목적, 플랫폼에 필요한 접근 범위, 거부해도 수동 일정 등록이 가능함을 설명한다.
- 캘린더 이름과 공급자를 색상 외 텍스트로 표시하고 전체·Google·Apple/iCloud·기기별로 필터링한다.
- 일정명·날짜·시간·장소를 확인할 수 있으며 종일 일정은 시간이 없음을 명시한다.
- 일정 카드를 눌러도 초안은 바뀌지 않고 `이 일정 가져오기`를 누른 뒤에만 새 일정 초안에 병합한다.
- 권한 거부·차단, 연결 캘린더 없음, 조회 기간 일정 없음, 조회 실패, 앱 복귀 상태에서 가능한 다음 행동을 제공한다.
- 캘린더 원문은 기기에서만 읽고 ON:TIME에 가져오기로 선택한 필드 외에는 서버나 앱 영구 저장소로 복제하지 않는다.

### 실시간 진행

준비 알림 → 현재 단계 → 완료 → 다음 단계 → 도착.

- 상단에 약속 시간, 예상 도착, 여유/지연 문구를 유지한다.
- 현재 단계와 남은 시간을 화면에서 가장 크게 표시한다.
- 잘못 누른 완료를 취소할 수 있고 앱 복귀 시 상태가 유지된다.

### 지연과 플랜 B

시간 더 필요 → 재계산 → 변경 요약 → 적용/유지 → 진행.

- 해결 방법을 지연 사실보다 먼저 보여준다.
- 변경 전후의 출발/도착/준비 시간 차이를 표시한다.
- 최대 3안에 예상 도착, 비용, 걷기, 환승, 정시 여부, 추천 이유를 표시한다.
- AI가 중요한 행동을 임의로 삭제하지 않는다.

## 상태 요구사항

반드시 일정 없음, 준비 전, 준비 시간 경과, 정상 진행, 지연, 정시 불가능, 네트워크 오류, 위치 권한 거부, 알림 권한 거부, 완료 상태를 제공한다.

## 지표

- 첫 일정 생성 완료율과 소요 시간
- 알림에서 준비 시작으로 전환한 비율
- 지연 제안 확인/적용/거절 비율
- 계획 대비 실제 단계 오차
- 정시 또는 약속 전 도착률

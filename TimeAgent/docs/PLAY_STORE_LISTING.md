## 짧은 설명

## 자세한 설명

TimeAgent는 약속에 늦지 않도록 준비 시작 시각부터 출발, 이동, 도착까지 한 번에 계획해 주는 시간 관리 앱입니다.

오늘 일정을 홈에서 확인하고, 약속 시각·장소·이동수단·준비 행동을 입력하면 필요한 시간을 역산합니다. 진행 중에는 지금 해야 할 행동과 남은 시간을 가장 먼저 보여주며, 늦어졌을 때는 다음 행동과 변경된 도착 예상 시각을 제안합니다. 변경은 사용자가 확인하고 적용할 때만 반영됩니다.

주요 기능

- 오늘 일정과 다음 행동을 홈에서 바로 확인
- 현재 위치 날씨와 일정에 필요한 우산·겉옷·물 준비 안내
- 준비 행동, 이동 시간, 여유 시간을 반영한 계획 생성
- 진행 상황에 맞춘 남은 시간과 단계별 알림
- 지연 시 Plan B와 변경 전후 비교 제공
- Google 로그인과 기기 캘린더 일정 가져오기
- 음성으로 일정 초안 만들기
- 사용자가 선택한 경우 화면이 꺼진 이동 중에도 위치 기반 다음 행동 안내

백그라운드 위치는 이동 안내 화면에서 사용자가 직접 켠 동안에만 사용합니다. 25m 이동 또는 15초 간격으로 다음 이동 행동과 도착 예상 시간을 갱신하며, 광고나 판매 목적으로 사용하지 않습니다. 사용자가 안내를 끄거나 목적지에 도착하면 추적을 중지하고 해당 이동 세션의 위치 기록을 삭제합니다.

TimeAgent의 제안은 언제든 적용하거나 거절할 수 있습니다.

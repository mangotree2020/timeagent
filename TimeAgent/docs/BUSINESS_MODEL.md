# ON:TIME 비즈니스 모델 설계

> 상태: 수익화 가설 v1
>
> 기준일: 2026-07-28
>
> 적용 원칙: 가격·전환율·비용은 출시 확정값이 아니라 검증 대상이다. 사용자의 일정·위치·음성 데이터는 판매하지 않는다.

## 1. 결론

ON:TIME의 1차 수익모델은 **B2C 프리미엄 구독**, 2차 수익모델은 **학교·코칭·복지 조직 대상 B2B2C 라이선스**로 설계한다.

ON:TIME은 또 하나의 캘린더가 아니다. 사용자가 약속 시각을 알고도 준비를 늦게 시작하거나 이동 중 계획이 어긋나는 문제를 해결한다. 따라서 결제 대상은 일정 저장 자체가 아니라 다음의 반복적 성과다.

- 약속에서 역산한 준비 시작 시각
- 지금 해야 할 행동 하나의 명확한 안내
- 지연 감지 후 도착 가능한 계획으로 재계산
- 사용자의 실제 준비 시간을 학습한 개인화
- 음성 입력·캘린더 연동으로 줄어드는 계획 비용

광고 모델은 채택하지 않는다. 출발·지연처럼 집중이 필요한 순간에 광고가 핵심 행동을 방해하고 신뢰를 훼손하기 때문이다. 제휴 수수료는 충분한 사용성과 사용자 동의가 확인된 뒤, 교통 예약처럼 사용자에게 명백한 편익이 있는 경우에만 별도 실험한다.

## 2. 사용자 페르소나: 페인포인트 → 솔루션

### P1. 마감 직전형 대학생 — 초기 확산 사용자

**상황**

수업, 시험, 면접, 아르바이트 일정은 알고 있지만 준비를 언제 시작해야 하는지 매번 다시 계산한다. 생활 리듬과 이동 시간이 일정하지 않고 가격에 민감하다.

**페인포인트**

- 캘린더 알림이 울릴 때는 이미 준비가 늦었다.
- 준비·이동·버퍼 시간을 낙관적으로 잡는다.
- 여러 단계의 준비 목록을 보면 시작을 미룬다.
- 한 단계가 늦어지면 전체 계획을 포기한다.

**ON:TIME 솔루션**

- 약속 시각에서 준비·이동 시간을 역산한다.
- 홈과 라이브 화면에서 지금 할 행동 하나를 우선 표시한다.
- 지연 시 새 출발 시각과 Plan B를 제안한다.
- 실제 소요 시간을 다음 계획에 반영한다.

**지불 계기**

시험·면접·첫 출근처럼 지각 비용이 큰 일정이 생기거나, 2주 안에 스마트 계획을 반복해서 사용하는 시점이다. 학생 할인 없이는 유료 전환이 낮을 가능성이 크다.

### P2. 연속 일정형 직장인·프리랜서 — 핵심 지불 사용자

**상황**

외부 미팅, 출근, 출장, 병원, 가족 일정이 이어진다. 캘린더는 회의 시작 시각을 알려주지만 준비와 이동은 관리하지 않는다.

**페인포인트**

- 앞 일정이 길어지면 뒤 일정의 준비·이동 계획이 즉시 무너진다.
- 장소와 교통수단마다 필요한 버퍼가 다르다.
- 지각이 신뢰·매출·평가 손실로 이어진다.
- 이동 중 일정 입력과 수정이 번거롭다.

**ON:TIME 솔루션**

- 기기 캘린더를 가져와 준비 시작 시각을 자동 생성한다.
- 이동수단·비용 우선순위를 반영해 계획과 대안을 제안한다.
- 음성으로 일정과 준비 행동을 빠르게 추가·수정한다.
- 연속 일정의 지연을 감지해 다음 행동을 다시 제시한다.

**지불 계기**

주 2회 이상 이동 일정이 있고, 한 번의 지각 방지만으로 월 구독료 이상의 손실을 피할 수 있다고 느끼는 시점이다.

### P3. 준비 루틴 변동형·시간 감각 취약 사용자 — 핵심 유지 사용자

**상황**

준비 시간이 날마다 크게 달라지고, 행동 전환이나 남은 시간 감각에 어려움을 느낀다. 이는 의료적 진단 여부와 무관한 사용 맥락이다.

**페인포인트**

- “곧 시작”과 “지금 시작”의 경계가 모호하다.
- 준비 단계를 머릿속에 유지하는 데 에너지가 많이 든다.
- 반복 독촉은 스트레스를 높이고 결국 알림을 끄게 한다.

**ON:TIME 솔루션**

- 색상 외에 문구·숫자·음성으로 상태와 남은 시간을 전달한다.
- 다음 행동 하나, 완료 확인, 부드러운 재안내를 제공한다.
- 사용자의 실제 루틴을 학습하되 변경은 항상 제안으로 보여준다.
- 화면 읽기, 큰 터치 영역 등 접근성은 무료·유료와 무관하게 유지한다.

**지불 계기**

반복 일정에서 스트레스가 줄고 실제 출발이 빨라지는 경험이 누적되는 시점이다. 의료 효과를 약속하거나 진단명을 마케팅 타기팅에 사용하지 않는다.

### P4. 보호자·코치·학교·복지 조직 — 후속 구매자

**상황**

당사자의 독립적인 일정 수행을 돕고 싶지만 반복 연락과 수동 확인에 운영 비용이 든다.

**페인포인트**

- 매 일정마다 준비 시작을 대신 알려줘야 한다.
- 일률적인 체크리스트는 개인별 루틴 차이를 반영하지 못한다.
- 민감한 개인 일정을 공유하면 프라이버시 위험이 생긴다.

**ON:TIME 솔루션**

- 조직용 일정·준비 템플릿을 배포한다.
- 사용자가 명시적으로 동의한 최소 상태만 공유한다.
- 개인 일정 내용이 아닌 집계된 활성화·완료 지표를 제공한다.

**구매 계기**

상담·출결·생활 지원의 반복 연락 시간이 줄어드는 것이 소규모 파일럿에서 확인되는 시점이다. 이 기능은 동의 철회, 공유 범위, 감사 기록을 갖추기 전에는 판매하지 않는다.

## 3. 핵심 Job-to-be-Done

> 중요한 일정이 있을 때, 내가 늦지 않도록 해야 할 일을 적절한 시각에 시작하고, 계획이 어긋나도 포기하지 않고 도착 가능한 다음 행동을 알고 싶다.

| 사용자 문제 | 제품 해결 | 체감 가치 | 수익화 대상 |
|---|---|---|---|
| 알림 시점에는 이미 늦음 | 준비·이동 역산 | 제때 시작 | 기본 경험은 무료, 자동화 횟수는 유료 확장 |
| 계획 작성이 번거로움 | 캘린더·음성 입력 | 입력 시간 절감 | 무제한 자동 가져오기·AI 음성 |
| 준비 시간이 매번 다름 | 실제 시간 학습 | 계획 정확도 향상 | 고급 개인화·루틴 리포트 |
| 한 단계 지연 후 계획 포기 | 실시간 재계산·Plan B | 지각 감소·회복감 | 무제한 스마트 재계산 |
| 반복 독촉으로 피로함 | 행동 하나·상태별 알림 | 인지 부담 감소 | 접근성은 무료, 개인화 강도는 유료 확장 |

## 4. 시장 내 위치

경쟁 범주는 가격보다 해결하는 순간이 다르다.

| 범주 | 대표 서비스 | 주로 해결하는 문제 | ON:TIME의 차별점 |
|---|---|---|---|
| 기본 캘린더 | Apple·Google Calendar | 일정 기록·초대·시각 알림 | 약속 전에 준비를 시작시키고 이동 지연을 회복 |
| 시각적 데일리 플래너 | Structured·Tiimo | 하루 루틴 시각화·집중 지원 | 실제 도착 시각에서 역산하고 경로 변화에 재계산 |
| AI 일정 최적화 | Motion·Reclaim | 업무·할 일의 캘린더 자동 배치 | 개인의 준비·이동 실행과 현장 복귀에 집중 |

공식 공개 페이지 기준으로 Reclaim은 무료 플랜과 좌석당 월 $10·$15·$22의 유료 플랜을, Motion은 좌석당 월 $19·$29의 AI 플랜을 제시한다. Tiimo는 무료 버전과 월·연간 Pro, Structured는 무료 시작과 Pro 업그레이드를 운영한다. 국가·결제주기·스토어에 따라 실제 가격은 달라질 수 있다.

ON:TIME은 업무 생산성 제품보다 좁고 일상적인 문제를 다루므로, 초기 개인 요금은 이들 AI 업무 도구보다 낮게 검증한다. 무료 캘린더와 경쟁해 “일정을 저장하는 비용”을 받지 않고, **지각 위험이 있는 일정을 실행 가능한 계획으로 바꾸는 자동화**에 비용을 받는다.

## 5. 상품과 가격 가설

### 5.1 Free — 핵심 가치 검증

가격: 무료

- 수동 일정·준비 행동 생성과 수정
- 월 5회의 스마트 계획: 역산 계획 + 지연 재계산
- 캘린더 1개 가져오기
- 월 10회의 AI 음성·텍스트 일정 정리
- 기본 알림, 체크리스트, 최근 7일 기록
- 모든 접근성 기능, 데이터 내보내기·삭제, 오프라인 수동 경로

무료 플랜은 첫 성공을 충분히 경험할 수 있어야 한다. 월 한도를 초과해도 기존 일정 조회, 수동 편집, 핵심 알림은 중단하지 않는다.

### 5.2 ON:TIME Plus — 주 수익원

가격 가설:

- 월간 **₩5,900**
- 연간 **₩49,000**: 월 환산 약 ₩4,083, 월간 대비 약 31% 할인
- 활성화 이후 14일 체험: 첫 계획 완료 전에는 체험 카운트를 시작하지 않음

유료 가치:

- 스마트 계획·지연 재계산·AI 입력 무제한(공정 사용 한도 적용 가능)
- 여러 캘린더 자동 가져오기와 변경 동기화
- 실제 준비 시간 기반 개인 루틴 학습
- 교통수단·비용 우선순위 기반 Plan B
- 30일 이상 기록, 주간 리포트, 지각 위험 패턴
- 향후 계정·기기 간 동기화와 위젯 등 프리미엄 편의 기능

“무제한”은 남용 방지를 위한 합리적 사용량 정책과 함께 운영한다. 현재 구현된 기능이 자동으로 유료화된다는 뜻이 아니며, 결제·복원·권한·고지 수용 기준을 갖춘 뒤 별도 출시한다.

### 5.3 학생 연간 플랜 — 확산과 접근성

- 인증된 학생 대상 연 **₩29,000** 가격 가설
- 월간 학생 상품은 두지 않고 연간 상품으로 결제 복잡성과 이탈을 줄임
- 인증 비용이 할인으로 얻는 전환 이익보다 큰지 먼저 검증

### 5.4 Family/Support — 후속 상품

- 최대 4명, 월 **₩8,900** 또는 연 **₩79,000** 가격 가설
- 가족별 비공개 공간, 선택적 준비 템플릿 공유, 최소 상태 체크인
- 위치 상시 공유나 일정 원문 공유는 기본값으로 제공하지 않음

### 5.5 B2B2C 라이선스 — 두 번째 성장축

- 대학 학생지원, 취업 코칭, 복지·생활지원 기관에 8~12주 유료 파일럿
- 가격 가설: 활성 사용자당 월 **₩2,500~₩4,000**, 최소 계약액 별도
- 제공 가치: 템플릿 배포, 온보딩, 익명 집계 리포트, 관리자 지원
- 성공 조건: 반복 연락 시간 감소와 사용자 활성·일정 완료 향상이 동시에 확인될 것

개인 일정을 광고·보험·고용 평가 데이터로 판매하는 기업 계약은 하지 않는다.

## 6. 결제 전환 설계

### 활성화 정의

다음을 모두 충족하면 활성 사용자로 본다.

1. 일정 생성 또는 캘린더 가져오기 완료
2. 60초 안에 준비·이동 계획 확인
3. 알림에서 준비 시작 또는 첫 행동 완료
4. 일정 종료 후 실제 시간을 최소 한 번 기록

### 결제 제안 시점

- 가입 직후가 아니라 **스마트 계획 3회 완료 후** Plus 가치를 설명한다.
- 무료 한도의 마지막 1회를 쓰기 전에 남은 횟수를 투명하게 보여준다.
- 여러 캘린더, 자동 동기화, 30일 리포트처럼 사용자가 직접 요청한 프리미엄 기능 진입 시 맥락형 결제 화면을 보여준다.
- 지연·출발 직전에는 결제 화면을 띄우지 않는다. 안전하고 긴급한 다음 행동을 먼저 제공한다.

### 가치 증명 문구

“AI로 더 생산적으로”보다 관측 가능한 결과를 보여준다.

- “이번 주 4개 일정에서 준비를 제때 시작했어요.”
- “실제 준비 시간에 맞춰 다음 알림을 12분 앞당겼어요.”
- “오늘 일정은 지연 후 새 계획으로 전환했어요.”

절약 시간이나 지각 방지 횟수는 계산 근거가 있을 때만 표시한다.

## 8. 핵심 지표와 출시 게이트

목표치는 외부 벤치마크가 아니라 초기 검증을 위한 내부 가설이다.

| 단계 | 핵심 지표 | 초기 목표 가설 |
|---|---|---:|
| 획득 | 스토어 방문 → 설치 | 채널별 측정 후 기준선 설정 |
| 활성화 | 설치 → 첫 스마트 계획 확인 | 60% 이상 |
| 첫 가치 | 첫 계획 생성까지 걸린 시간 | 중앙값 60초 이하 |
| 행동 | 알림 → 준비 시작 | 주차별 개선 |
| 제품 성과 | 계획 대비 실제 준비 오차 | 4주 내 감소 |
| 유지 | D7 유지율 | 25% 이상 |
| 습관 | 14일 내 스마트 계획 3회 완료 | 30% 이상 |
| 수익 | 체험 → 결제 | 20% 이상 |
| 유지 수익 | 월 유료 이탈률 | 8% 이하 |
| 경제성 | 유료 사용자 공헌이익률 | 70% 이상 |

가장 중요한 북극성 지표는 단순 DAU가 아니라 **주간 제때 준비를 시작한 일정 수**다. 보조 지표로 `알림 → 시작 전환율`, `지연 제안 수락률`, `계획 대비 실제 시간 오차`, `제시간 도착 자기보고율`을 함께 본다.

## 9. 단계별 수익화 실행 계획

### Phase 0 — 지불 의사 검증, 2~4주

- 활성 사용자 50~100명의 일정 사용 빈도와 인터뷰를 확보한다.
- Plus 기능 설명 화면에서 가격안을 선택하고 `이 플랜에 관심 있어요`를 누르는 사전 수요 검증(fake-door)으로 관심을 측정하되 결제나 연락처는 받지 않는다.
- 참여자는 앱에서 일정·위치·음성 원문과 식별자를 제외한 기기 내 집계 결과를 미리 확인하고, 운영체제 공유창으로 직접 수신자를 선택해 전달한다. 앱은 자동 업로드하지 않는다.
- 직장인·학생을 분리해 월 ₩4,900 / ₩5,900 / 연 ₩49,000의 선택 이유를 조사한다.
- 첫 계획 완료율, 14일 내 3회 사용률이 출시 게이트에 못 미치면 결제 기능보다 활성화를 개선한다.

### Phase 1 — 개인 구독 MVP, 4~6주

- iOS·Android 인앱결제, 서버 영수증 검증, entitlement를 구현한다.
- 구매 복원, 만료·유예·환불 상태, 오프라인 상태를 구현한다.
- 무료 한도는 서버와 로컬에서 일관되게 계산하고 긴급 알림은 막지 않는다.
- 결제 화면에 가격, 갱신 주기, 체험 종료, 해지 방법을 명확히 표시한다.
- 분석 이벤트: paywall view, trial start, purchase, renewal, cancel, restore, entitlement error.

### Phase 2 — 가격·패키지 최적화, 4주 이상

- 첫 가치 전/후 결제 제안 시점을 비교한다.
- “무제한 자동 계획”과 “개인화 리포트” 중 결제 동기를 인터뷰와 선택률로 비교한다.
- 학생 연간 플랜의 인증 비용, 전환 상승, 유지율을 검증한다.
- 월별 사용자당 지도·AI 원가 상한 알림을 운영한다.

### Phase 3 — B2B2C 파일럿

- 한 개 기관, 30~100명, 8~12주로 시작한다.
- 사용자 동의율, 주간 활성화, 완료율과 담당자 반복 연락 시간을 사전·사후 비교한다.
- 조직 관리자에게 개인 일정 원문이나 실시간 위치를 제공하지 않는다.
- 개인 사용자의 만족도 또는 자율성이 낮아지면 계약 확대를 중단한다.

## 12. 의사결정 원칙

1. 결제 전에 최소 세 번의 핵심 가치를 경험하게 한다.
2. 사용자의 긴급한 다음 행동보다 결제 전환을 우선하지 않는다.
3. 접근성, 데이터 이동·삭제, 수동 핵심 기능은 유료 잠금하지 않는다.
4. 일정·위치·음성 원문을 광고나 데이터 판매에 사용하지 않는다.
5. AI 결과는 자동 강제가 아니라 적용·수정·거절 가능한 제안이다.
6. 수익 최적화는 “주간 제때 준비 시작 일정 수”가 악화되지 않는 범위에서만 진행한다.

# 디자인 시스템

## 최종 방향

HTML 시안의 **Timeline Coach**를 채택한다.

- 타임라인 중심형의 맥락과 신뢰
- 카운트다운 중심형의 즉시성
- AI 코치 중심형의 해결 중심 설명

현재 단계만 네이비 카드로 확장해 “타임라인 속 스포트라이트”를 만든다. 홈에서는 다음 일정과 준비 시작 시점을 우선하고, 진행 화면에서는 현재 행동과 남은 시간을 우선한다.

## 원칙

- Calm, Smart, Adaptive, Time-focused, Action-oriented, Minimal
- 한 화면에 하나의 핵심 CTA
- 불안을 키우는 표현 대신 현재 상태와 해결 방법 제시
- AI 판단 근거는 한두 문장으로 표시
- 주요 CTA는 하단 엄지 영역에 배치

## 컬러

| 역할 | 토큰 | 값 |
|---|---|---|
| 핵심 네이비 | `navy` | `#03045E` |
| 주요 액션 | `deepBlue` | `#0077B6` |
| AI/현재 강조 | `cyan` | `#00B4D8` |
| 보조 배경 | `ice` | `#CAF0F8` |
| 앱 배경 | `background` | `#F4FAFD` |
| 정상/여유 | `success` | `#0D9488` |
| 주의/시간 부족 | `warning` | `#B45309` |
| 지각/오류 | `danger` | `#C2413A` |

모든 상태 색에는 `4분 여유`, `6분 지연`, `8분 지각 예상` 같은 문구를 병행한다.

## 타이포그래피

- 카운트다운: 44-58px, 900 weight
- 화면 제목: 24-25px, 900 weight
- 현재 행동/카드 제목: 18px 이상, 800-900 weight
- 본문: 16px, line-height 24px
- 보조 문구: 13-15px. 핵심 설명에는 16px 사용

숫자는 시각적으로 가장 강하지만 의미 단위와 상태 문구를 함께 둔다.

## 컴포넌트 계약

- `Screen`: 최대 폭 560px, 안전 영역, 스크롤과 하단 CTA 공간 보장
- `Card`: 과도한 그림자 대신 면, 테두리, 여백으로 구분
- `StatusPill`: 텍스트가 포함된 상태 레이블
- `Button`: 최소 높이 52px, primary/secondary/ghost
- `Timeline`: 완료 축소, 현재 확장, 예정 간소화, 변경 표시
- `BottomNav`: 홈/일정/알림/설정의 최대 4개 항목

## 아이콘 시스템

- 소스: [Lucide](https://lucide.dev), ISC 라이선스의 무료 오픈소스 아이콘 세트
- 구현: `lucide-react-native` + Expo 권장 `react-native-svg`
- 선택 원칙: 같은 의미는 전 화면에서 같은 아이콘을 사용하고 문자·이모지·임의 기호를 아이콘으로 사용하지 않는다.
- 크기: 보조 16px, 본문 20px, 하단 내비게이션 22px, 교통·완료 강조 28px
- 선 굵기: 기본 2px, 선택된 내비게이션과 주요 액션만 2.5px
- 아이콘 전용 버튼: 시각 크기와 관계없이 최소 44×44px 터치 영역과 텍스트 접근성 레이블 제공
- 카드 아이콘: 40–48px 원형 컨테이너 안에 20–28px 아이콘을 배치해 기준선과 밀도를 통일
- 색상: 기본 `deepBlue`, 비활성 `textMuted`, 선택·AI 강조 `cyan`; 색만으로 상태를 전달하지 않는다.
- 성능: 배럴 전체가 아닌 개별 아이콘 경로를 import해 개발 bundle과 앱 bundle에 필요한 아이콘만 포함한다.

현재 선별한 의미 체계는 홈, 일정, 알림, 설정, 위치, 시간, AI 코치, 음성, 준비 루틴, 샤워, 화장, 의복, 가방, 도보, 버스, 지하철, 자동차, 택시, 닫기, 증감, 완료, 다음 이동이다.

## 화면 체크

- 기준 크기: 360x800, 390x844, 430x932
- 최소 터치 영역 44x44px
- 폰트 확대 시 텍스트 잘림 금지
- 야외 밝은 환경을 고려한 대비
- 모션은 300ms 안쪽의 상태 전환에 한정하고 시간 압박 중에는 생략 가능

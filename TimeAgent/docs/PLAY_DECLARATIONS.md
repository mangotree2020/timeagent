# Google Play 정책 선언 초안

## 백그라운드 위치

핵심 목적: 사용자가 이동 안내를 명시적으로 시작한 동안 화면이 꺼지거나 앱이 백그라운드에 있어도 현재 위치를 바탕으로 다음 이동 행동, 남은 거리, 도착 예상 시간을 안내한다.

앱 내 명확한 고지:

> TimeAgent는 화면이 꺼지거나 앱을 사용하지 않는 동안에도, 사용자가 켠 이동 안내를 계속하기 위해 위치를 사용합니다. 위치는 25m 이동 또는 15초 간격으로 다음 행동과 도착 예상 시간을 갱신하는 데 사용하며, 해당 이동 세션 동안 기기에 임시 저장됩니다. 광고나 판매에 사용하지 않으며 안내를 끄거나 도착하면 저장 위치를 삭제합니다.

권한 요청 순서:

1. Journey 화면에서 위 고지와 `나중에` 선택지를 표시한다.
2. 사용자가 `화면 꺼짐 안내 켜기`를 선택한 뒤에만 시스템 권한 화면으로 이동한다.
3. 거절해도 포그라운드 안내와 수동 출발지 기능을 제공한다.
4. 설정과 Journey 화면에서 언제든 중지할 수 있다.

제출 영상(30초 이내) 촬영안:

1. Journey 화면과 백그라운드 위치 고지 표시
2. 사용자가 켜기 버튼 선택
3. Android 시스템의 `항상 허용` 선택
4. 화면을 끄거나 홈으로 이동
5. 위치 foreground-service 알림과 다음 행동 안내 표시
6. 앱으로 돌아와 끄기 및 중지 상태 표시

## Foreground service

### location

- 사용자 인지 작업: 사용자가 시작한 목적지 이동 안내
- 사용자 가치: 화면이 꺼져도 다음 행동과 도착 예상 시간이 이어짐
- 시작/중지: Journey 화면에서 명시적으로 시작하고 언제든 중지, 도착 시 자동 종료
- 영상: 백그라운드 위치 제출 영상과 동일 흐름 사용 가능 여부를 Console에서 확인

백그라운드 미디어 재생은 사용하지 않으므로 Expo Audio의 background playback을 끄고 `FOREGROUND_SERVICE_MEDIA_PLAYBACK` 권한과 서비스를 출시 manifest에서 제거한다.

## 앱 액세스

앱 실행 시 Google 로그인이 필요하다. Play 심사용 전용 Google 계정을 만들고, 2단계 인증이나 개인 기기 승인이 필요 없는 접근 지침을 Console에 제공한다. 개인 계정 비밀번호를 저장소나 이 문서에 기록하지 않는다.

## 콘텐츠 및 대상 사용자

- 광고 없음
- 아동 대상 앱으로 설계되지 않음
- 위치, 캘린더, 마이크는 기능을 선택했을 때만 요청
- 건강·금융·정부 기능 없음

콘텐츠 등급 설문은 실제 화면과 문구에 따라 Console에서 다시 검토한다.

# ON:TIME 작업 규칙

## 우선순위

1. 사용자가 지금 해야 할 행동과 남은 시간을 가장 먼저 보여준다.
2. 지연 사실만 알리지 말고 해결 가능한 다음 행동을 함께 제시한다.
3. AI의 변경은 제안이며 사용자가 적용, 수정, 거절할 수 있어야 한다.
4. 색상만으로 상태를 전달하지 않는다.

## 구현 규칙

- Expo SDK와 React Native 버전은 `package.json`을 기준으로 한다.
- 라우트는 `src/app`, 재사용 UI는 `src/components`, 상태는 `src/state`, 순수 계산은 `src/lib`에 둔다.
- 시간 계산과 재계산 로직은 UI에서 분리하고 단위 테스트를 먼저 추가한다.
- 본문은 16px을 기본으로 하고 모든 핵심 터치 영역은 최소 44x44px을 유지한다.
- 핵심 CTA는 한 화면에 하나만 시각적으로 우선한다.
- 네트워크/권한/빈 상태/복귀 상태를 성공 경로와 함께 구현한다.
- 새 라이브러리는 Expo 호환 여부를 확인하고 `npx expo install`을 우선 사용한다.

## 완료 조건

- `npm run verify` 통과

- 변경된 수용 기준과 테스트 증거를 `docs/EXECUTION_PLAN.md`에 반영
